# 📄 AnalyzeIt

> AI-Powered Recruitment & Resume Intelligence Platform

AnalyzeIt is an AI-powered recruitment assistant that helps recruiters intelligently analyze resumes, match candidates to job descriptions, perform semantic search using RAG, generate interview questions, and make AI-assisted hiring decisions using local LLMs.

---

## ✨ Features

- 📄 Resume Parsing
- 💼 Job Description Parsing
- 🤖 AI Candidate Ranking
- 🔍 Semantic Resume Search (RAG)
- 📊 Recruiter Analytics Dashboard
- 👥 Candidate Comparison
- 🎤 AI Interview Question Generator
- 📝 AI Hiring Recommendations
- 🌐 Multilingual Resume Queries
- 📤 PDF, CSV & Excel Export

---

## 🛠 Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3
- BGE-M3 Embeddings
- NumPy
- PyPDF
- Plotly

## Installation

```bash
git clone https://github.com/AgrawalDaksh/AnalyzeIt.git

cd AnalyzeIt

pip install -r requirements.txt

streamlit run app.py
```
